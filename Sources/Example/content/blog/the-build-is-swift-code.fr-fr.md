---
date: 2026-01-12
title: Le build est du code Swift
description: Pourquoi le pipeline de Calgary est du code plutôt qu'un fichier de configuration.
---

La plupart des générateurs de sites statiques sont pilotés par un fichier de
configuration. Calgary prend le parti opposé : le build est un exécutable que
vous écrivez — un `Site` configuré avec des étapes en chaîne.
